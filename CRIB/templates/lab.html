Controlled TCP Network Lab

Safe, isolated local loopback environment for practical networking and detection testing.

Boundary: Strictly 127.0.0.1
Controlled Environment Guarantee: All exercises in this lab are programmatically confined to the local loopback interface (127.0.0.1) and unprivileged user ports (1024–65535). No packets ever leave this host, ensuring safe, repeatable experimentation.
1. Local TCP Echo Service {% if lab_status.active_services_count > 0 %}LISTENING{% else %}STANDBY{% endif %}

Starts or stops a background TCP echo socket listener on loopback port 9100 to accept and reply to test handshakes.

2. Loopback TCP Socket Probe

Transmit an actual TCP payload to a local port and inspect socket return data and millisecond latency.

3. Local Port State Verification

Verifies the TCP connection state (OPEN / CLOSED) across designated lab ports (9100–9103) on 127.0.0.1.

4. Trigger Detection Demonstration

Generates a rapid sequence of 12 distinct TCP connection requests to simulate a port scan and trigger the CRIB Detection Engine.
